# TEST 하루 루프 (DayLoop)

`해달식당_하루루프_화면및기능_수정지시서` 중 코드로 처리할 수 있는 항목을 TEST 씬에만 적용한 구현이다.

- 대상 씬: `StartScene_TEST`, `MainIsland_TEST`, `Restaurant_TEST` (`GameScenes` 상수 기준)
- **씬 파일(.unity)은 수정하지 않았다.** `DayLoopInstaller`가 위 씬이 열릴 때 필요한 컴포넌트를 런타임에 붙인다.
- 기존 씬(`Restaurant.unity` 등)에는 아무것도 설치되지 않는다. 공용 스크립트에는 기존 동작을 바꾸지 않는 훅(이벤트·읽기 전용 프로퍼티)만 추가했다.

## 하루 흐름

```
타이틀 → 인트로(새 게임만) → 섬(하루 시작) → 식당 준비 → 영업 → 입장 마감 → 결산 → 섬(다음 날)
```

| 단계 | 진입 조건 | 비고 |
| --- | --- | --- |
| 준비 | 식당 씬 로드 | 영업 불가 조건(메뉴 없음, 조리도구 없음, 직원 없음, 좌석 없음)이면 이유를 알리고 시작을 막는다 |
| 영업 | [운영 시작] | 배속 x1, 일시정지 해제 상태로 시작 |
| 입장 마감 | 오늘 입장할 손님을 모두 내보냄 (`CustomerSpawner` 큐가 빔) | 이미 들어온 손님은 끝까지 응대. 하루 손님 수는 스포너 설정값이며 고정 규칙이 아니다 |
| 결산 | 마지막 손님 퇴장 | 한 번만 실행. 장부 고정 → 평점 확정 → 다음 날 체크포인트 저장 |

마감 중 진행이 120초(게임 시간) 동안 없으면 남은 손님을 미대접으로 내보내고 결산에 따로 표시한다.

## 저장·복구 정책

파일에는 기존 설계대로 **하루 시작(DayStart) 체크포인트만** 기록한다.

- 결산 확정 = 다음 날 시작 체크포인트 저장 (날짜 +1, 골드·평점·결산 스냅샷을 한 파일에 함께 기록)
- 영업 도중 종료 → 그날 시작 시점부터 다시. 영업 중 번 골드도 함께 되돌아가므로 수익을 두 번 얻지 않는다
- 결산 화면에서 종료 → 이어하기 시 섬에서 저장된 결산을 다시 보여 준다 (매출 재지급 없음)
- 저장 실패 → 날짜를 넘기지 않고 결산 화면에서 재시도를 요구한다
- 에디터에서 게임 씬을 바로 실행한 임시 세션은 파일에 쓰지 않는다

`GameSaveData`에 `lastSettlement`, `settlementPendingReview`를 추가했다. 이전 세이브는 기본값(결산 없음)으로 읽힌다.

## 집계 기준

- 매출: 손님 결제 이벤트의 실제 지급액(팁 포함). 금액 팝업도 같은 이벤트를 쓴다
- 지출·기타 수입: 영업 중 골드 거래. 현재 비용 규칙이 없으면 지출 0이 정상이다
- 방문 = 생성(입장), 대접 = 계산 후 퇴장, 미대접 = 계산 없이 퇴장
- 순이익 = 매출 + 기타 수입 − 지출. 영업 중 골드 변화와 다르면 결산에 경고를 표시한다

## 평점

- 개인 평점 = 맛 점수(레시피 등급 − 식당 기대치에 따라 1.0~5.0) + 최애 메뉴 보너스 0.5 (최대 5.0)
- 오늘 평점 = 오늘 개인 평점의 평균
- 식당 평점 = 최근 7일 일일 평점의 평균. 실제 영업일이 7일 쌓이기 전에는 시작 평판 4.0(새 게임 시드)이 평균에 함께 들어간다
- 평가가 0건인 날은 평점 이력에 넣지 않는다 (0으로 덮어쓰지 않음)

## 파일

| 파일 | 역할 |
| --- | --- |
| `DayLoopInstaller` | TEST 씬 로드 시 자동 설치, 씬 이동을 `SceneTransition`으로 연결 |
| `SceneTransition` | 씬 전환 가림막. 다음 씬 초기화가 끝날 때까지 덮고, 중복 이동 요청을 무시 |
| `DayCycleController` | 식당 하루 단계, 영업 시작 검사, 마감·결산, 일시정지, TEST 씬 정리 |
| `DayLedger` | 당일 장부와 운영 측정값(자리 대기·주문 접수·음식 도착·첫 수익 시간) |
| `DayLoopSave` | 결산 확정 체크포인트, 결산 확인 기록, 결산 문구 |
| `RestaurantHud` | 영업 HUD (일차·단계·방문 n/N·자리 대기/남은 손님·골드·배속·일시정지) |
| `SettlementPanel` | 결산 카드 (순이익 → 대접·평점·골드 → 판매 내역 → 다음 준비) |
| `FirstDayGuide` | 준비 카드(매일), 첫날 첫 손님 안내 |
| `NpcStatusOverlay` | 손님·직원 상태 칩, 인내심 게이지, 식탁·운반 음식 아이콘, +nG 팝업 |
| `RestaurantCameraFramer` | 식당 구역 카메라를 고정 오브젝트 범위에 맞춤 (HUD 영역 확보, 화면비 대응) |
| `IslandDayHud` | 섬 상단 일차·골드, 결산 화면 복원 |
| `TitleTransitionGuard` | 인트로 중 타이틀 버튼 잠금 |
| `Editor/DayLoopSaveTests` | 결산 확정 저장 EditMode 테스트 |
