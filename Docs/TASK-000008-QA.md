## 실행 및 캡처 제한

지정된 캐시에 Assets·Packages·ProjectSettings를 복사하고 Library를 유지했다. 복사본의 productName만 `HaedalGame_Task000008_Capture`로 바꿔 실제 세이브 경로와 분리했다. 임시 캡처 스크립트는 복사본에만 두었다.

복사본 Unity 6000.3.8f1을 비배치 모드로 실행했으나 로컬 Package Manager IPC 연결에 실패했다. 캐시 패키지를 사용하는 `-noUpm` 재시도에서도 `LicenseClient-LEE` 연결 거부와 라이선스 초기화 시간 초과가 발생해 Play 모드에 진입하지 못했다. 수정 전 캡처를 이 사유로 건너뛰었으며, 구현 후 캡처도 실행하지 못했다. 권한 변경이나 외부 인증을 시도하지 않았다. 이번에 시작한 복사본 Unity 프로세스는 모두 종료했고, 종료 후 남은 Unity 프로세스가 없음을 확인했다.

남은 확인: Unity 실행 가능한 환경에서 모집 팝업의 스크롤·계약, 수량 직접 입력·담기·취소·장바구니 유지, 앞뒤 뒤집기 타이밍, 메뉴 화면 이탈 후 30초 제한 및 회귀 테스트 실행.
