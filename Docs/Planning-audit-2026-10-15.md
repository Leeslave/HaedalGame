## 검증

- Unity의 실제 Roslyn 응답 파일과 어셈블리 참조로 런타임 코드 컴파일 통과. 기존 미사용 필드 경고 2건.
- 에디터·NUnit 검증 코드 컴파일 통과.
- 실제 컴파일된 게임 어셈블리를 대상으로 .NET에서 순수 규칙 검증 통과: 능력치 12,000회, 등급 추첨 50,000회, 지원자·페널티 32개 조합, 선호 재료 20주기, 연구 데이터 18종.
- NUnit 회귀 검사 추가: 연구 시간 제한, 비용 예약의 원자성 및 다중 등급 환불, 취소 도안 소멸, 스카우트 비용·인원, 체불 처리와 중복 정산, 주민 방문 시 재료 미지급.
- 격리된 임시 프로젝트에서 Unity 통합 검증을 시도했으나 로컬 패키지 매니저 연결 실패 후 재시도에서 `No valid Unity Editor license found`로 종료됐다. **Unity 통합 테스트 및 실제 플레이/화면 검증은 미완료**다.
- 라이선스가 정상인 에디터에서 플레이 모드를 종료하고 `Haedal > Validation > Planning specification checks`로 회귀 검사를 실행할 수 있다. 결과: `Temp/PlanningAudit/planning-validation.txt`.

## 결정이 필요한 사항

1. 500G 모집 확률 원문은 70/30/10(합계 110). 현재 비율을 보존하여 약 63.64/27.27/9.09%로 정규화했다. 의도한 최종 확률 확인 필요.
2. 레벨별 폐업 기준 점수가 없어 모두 1.0, 경고는 1.3 이하로 두었다. `ClosureThresholds.json`에서 최종 수치를 지정할 수 있다. 실제 폐업 처리를 새로 추가한 것은 아니다.
3. 확정 28종 재료에는 유제품·버섯 등이 없어 종족별 특산물을 완전히 재현할 수 없다. 현재 존재하는 재료로 임시 매핑했으며 요정은 레몬, 곡물은 밀가루를 사용한다. 대응 재료가 없는 목장 종족은 출현 대상에서 제외한다. 최종 종족별 특산물 목록 또는 추가 재료 범위를 확인해야 한다.
4. 연구는 최신 확정 설명과 요리별 상세 문서를 우선하여 1회성 실습으로 구성했다. 이전의 일반 재료 20개/희귀 5개·1~3일 대기는 적용하지 않는다. 이를 다시 적용하려면 연구 비용·시간 정책을 별도로 확정해야 한다.

아트와 전용 컷신은 사용자와 논의 후 별도 작업한다. 이번 변경은 해당 아트 납품 완료를 의미하지 않는다.
