# 섬 주민 만화 컷신

섬 소식에서 주민을 처음 만나거나 각 섬의 세 번째 부탁을 완료하면 만화가 재생된다.
요정의 숲·돌고래의 바다·해달 왕국·곡물 섬·목장 섬의 첫 만남과 교류 완료, 총 10편이다.
각 장면은 3컷이며 오프닝과 같은 `ComicIntro` 재생기를 사용한다.

- 클릭: 대사 타이핑을 완성하거나 다음 컷을 보여 준다. 앞선 컷은 남는다.
- Space / Enter: 클릭과 동일하다. 기존 입력 관리자가 활성화된 경우에 지원한다.
- 건너뛰기 또는 마지막 컷 이후 클릭: 페이드아웃하고 섬 소식으로 돌아간다.
- 부탁·보상·교류 상태는 기존 규칙대로 처리된다.

## 그림과 대사

- 그림: `Assets/Resources/UIDesign/Art/IslandComic/{fairy,dolphin,kingdom,grain,ranch}.png`
- 각 그림은 3열 × 2행의 정규 아틀라스다. 윗줄은 첫 만남, 아랫줄은 교류 완료다.
- 원본 파일을 자르지 않고 런타임 스프라이트 영역으로 나눠 사용한다.
- 대사는 기존 `Assets/Resources/Dialogue/Island/*_arrival.json`, `*_done.json`에서 읽는다.
- 대사는 화자 방향으로 꼬리가 난 흰 타원 말풍선에 표시한다. 인물 얼굴을 가리지 않도록 컷 위에 공간을 확보한다.
- 서술은 각 컷 아래의 크림색 내레이션 상자에 표시한다. 원본 대사와 서술을 모두 한 번씩 넣는다.
- 말풍선은 `ComicSpeechBubble`의 UI 메시로 그리고, 글자는 TMP로 얹는다. 그림에 글자를 굽지 않아 타이핑과 즉시 완성을 유지한다.
- 이미지가 없으면 기존 대화 연출로 재생한다.
- 목재를 받는 마지막 이야기·출항 엔딩·에필로그는 기존 대화 연출을 사용한다.

그림은 내장 image_gen으로 제작했다. 오프닝 `Intro/Cut1.png`, `Cut2.png`, `Cut3.png`,
`Cut5.png`의 단순한 얼굴·손그림 선·평면 채색을 기준으로 다시 제작했다.
요정과 돌고래는 사용자가 제공한 캐릭터 원본을 외형 기준으로 사용했다.
원본 사본은 `Art/References/IslandComic/Fairy.png`, `Dolphin.png`에 있다.
요정은 금발 단발·초록 눈·회색 드레스·하늘색 날개이며, 돌고래는 둥근 연보라색 몸과
짧은 주둥이·흰 배·작은 지느러미를 가진 모습이다. 돌고래에게 셰프 모자나 옷을 추가하지 않는다.
제작 프롬프트는 `Art/IslandComic-prompts.json`에 기록한다.
농부와 목장 장인의 외형은 이번 만화용 초안이다.

## 미리보기와 검증

Unity 메뉴 **Haedal → Validation → Island comic previews**를 실행하면
`Docs/Screenshots/IslandComic/`에 기존 오프닝과 주민 만화 10편의 1920×1080 미리보기를 만든다.
실제 세이브나 작업 중인 씬은 변경하지 않는다. 대사 넘침을 발견하면 검증을 실패 처리한다.

EditMode `IslandComicTests`는 10편의 그림 로딩·컷 해상도·대사 보존과
만화 대상이 아닌 장면의 기존 재생 경로를 검사한다.
플레이 모드에서 등장 애니메이션 중 클릭과 연속 스킵의 완료 콜백도 검사한다.

2026-11-23 검증 결과: `IslandComicTests` 15개, `SaveSystemTests` 19개 통과.
기존 오프닝과 주민 만화 10편을 1920×1080으로 렌더링했고 대사 넘침은 없었다.

화풍 수정판(revision 2)은 사용자 제공 요정·돌고래 원본을 반영해 30컷을 모두 교체했다.
돌고래 첫 등장 서술의 앞치마 표현도 새 그림에 맞춰 제거했다.

말풍선 적용판은 10장면의 대사·서술 45줄을 모두 배치했다(말풍선 27개, 내레이션 18개).
전체 장면의 말풍선 메시와 글자 넘침을 렌더링으로 확인했고,
대사 보존·실제 재생 시 말풍선 생성·빠른 클릭·중복 스킵을 포함한 `IslandComicTests` 15개가 통과했다.
