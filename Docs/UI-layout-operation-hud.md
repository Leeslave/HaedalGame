# 영업 HUD 배치 시안 — 2026-11-06

업무: TASK-000006. 목표는 주문·조리 서랍을 오른쪽 아래로 내려 펼쳐도 식당을 가리지 않게 하고, 밀려나는 직원 카드를 포함해 HUD 전체 자리를 다시 잡는 것이다.

이 시안은 실제 HUD 코드에 적용되어 있다. 대상은 `RestaurantHud`, `OrderDrawer`, `FirstDayGuide`이고 월드(`SeaRestaurantLayout`)는 건드리지 않았다.

## 화면에서 비어 있는 곳

1920×1080 기준(1유닛 = 54px). y는 화면 아래에서 잰 값이며, 실행 중인 게임에서 측정했다.

| 월드 요소 | 차지하는 범위 | HUD가 피할 이유 |
| --- | --- | --- |
| 주방 뗏목(지붕·갑판) | 약 x 830~1090, 그림 전체 x 636~1284 | 조리 장면 |
| 테이블 두 줄과 앉은 손님 | y 411~820, 화면 거의 전체 폭 | 핵심 플레이 영역 |
| 밧줄·기둥 | y 311~392 | 경계와 입구 |
| 밧줄 아래 손님 길 | y 242~342 | 입장·퇴장 경로 |
| 웨이팅석 | x 462~1458 (앉은 해달 포함 1470까지), y 81~306 | 대기 손님 |

비어 있는 곳은 **뗏목 왼쪽 위 바다**, **뗏목 오른쪽 위 바다**, **웨이팅석 양옆의 y 242 아래** 세 군데다. 시안은 HUD를 이 세 곳에만 둔다.

서랍 안쪽도 맞췄다.

- 패널 폭 660 → 400, 줄 높이 116 → 92, 음식 칸 80×88 → 80×72.
- 줄 제목을 세로 글자에서 가로 한 줄로 바꿨다.
- 제목 칸이 패널 폭의 절반을 차지하던 문제를 고쳐, 음식 칸 3개와 4번째 일부가 보인다. 칸이 넘치면 지금처럼 가로 스크롤된다.

## 측정 결과

Play 모드에서 x3 배속으로 돌리며 0.1초마다 HUD 사각형과 월드 스프라이트 사각형의 겹침을 쟀다. 시안 쪽 범위는 두 번 실행한 값이다. 스프라이트 사각형 기준이라 투명한 부분도 겹침으로 잡힌다. 손님 머리 위 주문 말풍선은 측정 대상이 아니다.

| 상황 | 이전 | 시안 |
| --- | --- | --- |
| 3레벨, 테이블 3개 | 서랍이 기둥 3개를 항상 가림 | 항상 가리는 것 없음. 퇴장 손님이 서랍 위쪽을 스치는 시간 0~1.8% |
| 10레벨, 1인석 9개, 긴 줄 | 서랍이 돌 의자를 항상 가림. 대기 손님과 66.8% 겹침. 직원·메뉴 카드도 돌 의자를 가림 | 서랍·직원·메뉴 모두 돌 의자와 대기 손님을 가리지 않음. 2번째 줄로 가는 손님이 메뉴 카드 뒤를 지나는 시간 약 30%, 퇴장 손님이 서랍 위쪽을 스치는 시간 0~3.8% |
| 10레벨, 4인석 9개 | 서랍이 테이블 2개·기둥 3개·돌 의자 3개를 항상 가림 | 항상 가리는 것 없음. 메뉴 카드 뒤를 지나는 시간 21~31%, 서랍 위쪽을 스치는 시간 0~1.6% |

직원 카드(4명)가 뗏목과 겹친다고 측정되지만 뗏목 그림의 투명한 윗부분이고, 화면에서 가려지는 그림은 없다.

4:3과 21:9에서도 서랍·직원·메뉴 카드가 월드 요소와 겹치지 않았다. (10레벨, 4인석 9개, 한 순간 측정)

## 고르지 않은 안

| 안 | 내용 | 고르지 않은 이유 |
| --- | --- | --- |
| 직원을 오른쪽 위 알약 줄 아래로 | 오른쪽 위에 묶음 | 안내 카드 자리와 겹치고, 오른쪽에 UI가 몰린다 |
| 직원을 서랍 왼쪽 옆으로 | 아래 줄에 나란히 | 웨이팅석을 가린다 |
| 서랍을 660px 그대로 | 음식 칸이 더 많이 보임 | 4레벨부터 웨이팅석 오른쪽을 가린다 (계산값) |

## 조정할 때 볼 값

- 서랍 폭: `OrderDrawer.PanelWidth`. 웨이팅석이 6자리 이하(4레벨까지)면 500px까지 늘려도 겹치지 않는다. (계산값) 5레벨부터는 겹치므로, 늘리려면 레벨에 따라 폭을 바꾸는 코드가 필요하다.
- 서랍 높이: `OrderDrawer.RowHeight`. 서랍 윗변이 y 242를 넘으면 손님 길을 가린다.
- 직원 카드 줄: `RestaurantHud.BuildTopLeft`.
- 메뉴 두 줄 기준: `RestaurantHud.MenuPerRow`.

## 남은 문제

- 7레벨 이상에서 웨이팅석이 두 줄이 되면, 왼쪽에서 들어온 손님이 2번째 줄로 가는 동안 메뉴 카드 뒤를 지나간다. 앉은 뒤에는 겹치지 않는다. 메뉴 카드를 접으면 줄어든다.
- 안내 카드는 윗줄 오른쪽 테이블 자리 2곳(3번째·9번째로 채워지는 자리)의 윗부분을 조금 가린다. (안내 중에는 게임이 멈춘다)
- 4:3 화면에서는 바다 배경이 위아래 끝까지 닿지 않아 검은 띠가 보이고, 일차·직원·서랍 카드가 그 위에 놓인다. 카메라와 배경 코드는 이번에 바꾸지 않았다.
- `FirstDayGuide`의 완료 안내 문구 "왼쪽 배속 버튼"은 이번 변경 전부터 실제 위치(오른쪽 위)와 다르다. 범위 밖이라 고치지 않았다.
