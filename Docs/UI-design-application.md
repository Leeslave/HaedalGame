## 새 UI와 리소스

기존 씬의 메뉴·로고·배경·음식·직원 UI 리소스를 다시 꾸미는 방식 대신, 새 Canvas와 전용 `Resources/UIDesign` 리소스로 구성했다. 원본 시안의 배경, 로고, 해달 이미지 3종, 음식 이미지 3종과 SVG 선 아이콘을 사용한다. 게임의 식당 월드, 저장 시스템과 거래 서비스는 기존 시스템에 연결한다.

- 타이틀: 원본 배경·로고·해달, 280px 메뉴 띠, 이어하기·새로하기·설정·종료 및 실제 저장 요약.
- 섬: 원본 섬 배경, 원형 건물 표식, 상태·미션·영업 준비·건물 메뉴·관리·설정.
- 영업 준비, 영업 HUD, 자리 배치, 결산: 새 사이드바와 카드·게이지·버튼. 배속 3단계, 배치 복원·철거, 실제 결산 장부와 연결.
- 관리 메뉴: 슬롯 띠·분류·4×2 메뉴 카드·상세. 재료는 재고 표, 직원은 2×2 초상화·능력 카드, 상점은 4×2 상품 카드·장바구니.
- 가구: 테이블·대기석·색상 4×2 카탈로그, 구매/창고 및 배치 연결. 현재 지원하는 1·2·4인석을 구매·배치하며 6인석은 잠금 표시다.
- 식당·도구, 엘프 상점, 연구: 목록과 상세, 레벨 조건·재고·구매·연구 예약 및 실습.
- 연구 실습: 원본의 작업대 배경·요리사·단계 목록·실습 패널·평균 점수 및 예약 재료 패널. 요리에 따른 실제 단계/조작을 사용한다.
- 탐험: 앞바다·갯벌·산호 숲, 직원 선택·출발·귀환·수확 수령. 파견 중인 직원은 영업에서 제외한다. 현재 일 단위 진행 규칙에 따라 앞바다도 다음 날 아침 귀환한다.
- 관리 집 탭: 할 일·미션·주급·저장 정보 2×2 카드. 밤의 집은 별도 새 화면으로 구성한다.
- 설정: 원본 타이틀 배경, 소리·화면 두 열, 음량 슬라이더·음소거 스위치·화면 모드·해상도·품질 선택·적용/취소.
- UI 키트: 시안의 색상, 외곽선, 그림자, 카드·칩·게이지·공통 버튼을 코드 컴포넌트에 반영했다.

시안의 1280×720 좌표를 기본으로 사용하며 공용 게임 UI는 동일한 비율인 1920×1080 단위로 구성한다. 시안의 예시 골드·인원·메뉴는 저장 데이터로 덮어쓰지 않고 실제 게임 값을 표시한다.

## 시작 시 한글 누락 수정

`Jua-Regular.ttf`, `NanumGothic-Bold.ttf`를 프로젝트에 포함한다. 폰트는 Google Fonts의 공식 `google/fonts` 저장소에서 받았으며 각 폰트의 OFL 라이선스도 함께 포함했다.

`DesignFonts`가 Resources에서 TTF를 직접 읽어 동적 TMP SDF와 다중 아틀라스를 만들고 제목/본문 폰트와 머티리얼을 함께 지정한다. 씬에 있는 기존 SDF의 글리프나 로딩 순서에 의존하지 않는다. `DesignFontBootstrap`은 씬 전환 시 대사/팝업을 포함한 구형 TMP 참조를 새 폰트로 보정한다.

실제 PlayMode 검사에서 발견한 Unity Object의 가짜 null 문제도 수정했다. 없는 CanvasGroup을 `??`로 검사하면 예외가 발생해 타이틀 생성과 폰트 보정이 중단되므로 명시적인 Unity null 검사 후 추가하도록 변경했다.

## 검증 결과

별도 복사본 `Temp/UIDesignCheckProject`에서 Unity 6000.3.8f1로 실행했다. 사용자 저장 파일과 현재 에디터 씬은 변경하지 않았다.

- Unity 컴파일 및 `python Docs/compile_check.py`: 런타임/에디터 어셈블리 통과.
- `UIDesignValidation.Run`: 한글 글리프 검사, 거래 테스트 5개 통과. 1920×1080으로 타이틀·섬·영업 준비·영업 HUD·배치·결산·실습·관리 11탭·집·설정 렌더링.
- 거래 검사: 재고 부족/골드 부족 주문의 부분 구매 방지, 정상 주문의 정확한 반영, 가구 구매 비용/창고, 탐험의 영업 인원 보호/중복 수령 방지.
- `UIDesignPlayValidation.Run`: 실제 시작 씬의 Awake/Start/폰트 보정 이후 타이틀 한글 메시와 섬·식당 준비 UI 설치 확인. 메모리상의 개발 세션만 사용했다.
- `git diff --check`: 공백 오류 없음.

## 재현

Unity 메뉴 `Haedal > Validation > UI design previews` 또는 `-executeMethod UIDesignValidation.Run`을 실행한다. 결과는 프로젝트 루트의 `UIValidation/`에 기록된다. PlayMode 배치 검사는 사용자 에디터를 건드리지 않도록 위 별도 검증 프로젝트에서만 실행할 수 있다.
